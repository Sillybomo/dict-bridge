# DictBridge 词库桥

把**你自己的**个人词库（搜狗/手打词表/任意文本）批量导入**微信输入法**的学习词库，Android 手机端全程操作。

原理：通过 LSPosed 在微信输入法引擎进程内调用其**自带的官方学习接口**（`add_user_history`），由引擎自己完成拼音推导、词频统计与落盘——**不修改输入法文件、不破解任何加密**，与你手动打字让输入法"学会"一个词完全等价，只是自动化了。

## 和现有工具的区别（写导入前请查证，也欢迎补充）

安卓微信输入法词库的**批量导入**，据我们所知此前没有任何公开方案——整个生态都在做"导出"：

| 项目 | 方向 | 与本项目差异 |
|---|---|---|
| [gowetype](https://github.com/YuleBest/gowetype) | 安卓 wetype → 其他（只读导出） | README 明示"所有读取都是只读的，不改任何文件"；无导入能力 |
| [imewlconverter / 深蓝词库转换](https://gitee.com/bdjlsk/imewlconverter) | 30+ 输入法格式互转 | 支持列表**不含**微信输入法（读、写都不含） |
| [wetype-dict-format](https://github.com/Glory0707/wetype-dict-format) | Windows 版词库逆向笔记 | 自称"只包含格式文档与解析工具"（只读） |
| [ime-lexicon](https://github.com/taxueseek/ime-lexicon) | 豆包/微信 词库文件层读写 | 面向**桌面版**词库文件（`usr.dat`/Windows LevelDB）；安卓端词库是带自定义校验的 LevelDB + 需 root 注入，其文件层方案不适用 |

本项目的差异化路线：**不碰文件格式**。安卓微信输入法的用户词库使用非标准 CRC 校验，直接改写文件会被引擎在恢复期静默丢弃（我们实测过，41 条真实记录对整个 CRC-32 参数族全不匹配）；与其逆向校验算法，不如调用引擎自己的学习接口，让它亲手写出完全合法的记录。也因此天然免疫词库格式升级——只要 `add_user_history` 还在官方 dex 里，工具就有效。

## 使用前提

| 条件 | 说明 |
|---|---|
| Root | KernelSU / Magisk 均可（用于 su 投递文件与授权） |
| LSPosed | Zygisk 版即可，需启用本模块 |
| 微信输入法 | 已安装且**启用过一次键盘**（引擎进程需存活） |
| 作用域 | LSPosed Manager 中给本模块勾选 `微信输入法`（建议同时勾选`小布输入法`，若你有该需求） |

## 快速上手（3 步）

1. 安装 `DictBridge-v0.4.1.apk`，在 LSPosed Manager 中启用模块、设置作用域、按提示重启微信输入法（或重开一次键盘）。
2. 准备词库文件：**每行一个词**的纯文本（UTF-8 或 GBK 自动识别；也支持 `拼音<Tab>词` 两列，自动取词列）。docx/xlsx 等 Office 文件会被导入前校验直接拒绝，请先另存为 .txt。
3. 打开"词库桥 DictBridge"应用 → 点"选择词库文件并导入微信输入法" → 选文件 → 等待完成提示。

完成后随便找个输入框打你的私人词验证。万级词表约 1~3 分钟。

### 结果里 `fail` 是什么？

引擎对**已在系统基础词库中**或**已在你的学习库中**的词会返回 false——这不是错误，这些词你本来就打得出来。实测 1.8 万词的个人词库，约 76% 需要学习、24% 基础库已覆盖，最终全部可打出。

### 多台设备怎么同步？

任意一台导好之后，其余设备**无需 root、无需本工具**：两台都打开微信输入法 →「换机助手」→ 扫码同步，个人词库会**合并**过去。

## 从搜狗导出词库（PC 辅助脚本，可选）

```bash
python tools/extract_sogou.py sgim_gd_usr.bin out.tsv   # 解出 词\t拼音\t词频
cut -f1 out.tsv > mywords.txt                            # 取词列成每行一词
```

`sgim_gd_usr.bin` 位于旧手机 `/sdcard/Android/data/<搜狗包名>/files/` 下（各版本路径略有差异）。不想用脚本的话，任何能导出"每行一词"文本的途径都可以。

## 常见问题

- **点了导入一直"等待引擎处理"**：微信输入法进程没活。随便点个输入框把键盘弹出来一次即可。
- **弹窗要 root 被拒了**：在 KernelSU/Magisk 里给本应用授权 root，重开应用。
- **多设备/多用户**：工具写死了微信输入法包名 `com.tencent.wetype`，ColorOS/OriginOS 实测可用；其他厂商输入法不在支持范围。
- **升级微信输入法后失效？** 本工具只调官方公开在 dex 里的静态接口，历史上未见过该接口移除；若真失效，欢迎提 issue。
