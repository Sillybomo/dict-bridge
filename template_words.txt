#
# 格式要求（就这几条）：
#   1. 纯文本文件，UTF-8 或 GBK 编码（自动识别），不要用 docx/xlsx
#   2. 每行一个词，例如：碎岩兽
#   3. 也接受两列「拼音<Tab>词」——词库软件导出的 tsv 可以直接传，
#      程序自动取最后一列的词；拼音列仅作保留，引擎会自己推导读音
#   4. 以 # 开头的行是注释，会被忽略；空行忽略；重复词自动去重
#   5. 单词最长 16 字；文件最大 32MB
#
# 注意：不需要（也无法）为每个词指定拼音——导入调用的是输入法自带的
#       学习接口，读音由引擎按词自动推导。
#
